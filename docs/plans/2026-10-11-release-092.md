# Plan: Release 0.9.2 (quality check, cache headers, list and feedback follow-ups)

Date: 2026-10-11 · Issues: #417, #418, #398 (rest), #399 (rest) · Branch: `agent/release-0.9.2` (from `develop`)

## Contents
1. **Cache headers (#417):** `SPAStaticFiles` sets `Cache-Control: no-cache` for `index.html`, the SPA fallback and other root files, `public, max-age=31536000, immutable` below `assets/` (content-hashed). A deployed build is picked up by the next load.
2. **Text quality (#418):**
   - `score_text_quality` counts words with a Unicode regex and treats accented vowels as vowels (was ASCII/German only), so French, Spanish, Polish, ... text is no longer penalized.
   - `services/ai/source_comparison.py`: `token_agreement` (share of shared distinct words of Paperless vs Vision text), `readability` (100 - penalty) and `recommend_source` (needs a gap of >= 5 points).
   - `GET /documents/{id}/ocr-scores` returns `agreement`, `recommended_source`, `recommendation_reason`.
   - UI: one readability scale (0-100, higher is better) with traffic light, "not measured" instead of `0.00` for a missing perplexity, penalties in a collapsed block, recommended source and agreement badges; the Suggestions guidance shows "Better text: ..." with an opt-in "Use it".
3. **List (#398):** the last used filters are restored when the list is opened without a query; the stats are one compact row (the duplicate "Processed*" is gone). The page size selector already exists in the filters. Merging presets and filters stays open.
4. **Feedback (#399):** the status pill names the running task ("Processing 4/10 · Vision OCR 3/12 · #2210 +1"), single applies (presets, "Use" on a variant) confirm with a toast that says the change is local until written back, the detail view shows a skeleton while a document loads.

## Not included
- Per-page readability and layout/reading-order heuristics (need thresholds calibrated on real documents).
- Merging presets and filters in the list header.
