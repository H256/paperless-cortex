# Plan: Documents list UX (slice 1 of #398)

Date: 2026-10-11 · Issue: #398 · Branch: `agent/398-list-ux` (from `develop`)

## Goal
Show why a document needs attention and how much is left, directly in the list.

## Design
- Preset counters from the review summary (#396): Unreviewed, Needs review, No correspondent, Issue date = import date. Presets without a known counter show none.
- Attention badges per row/card for not-reviewed documents: `No correspondent` (no id, name or pending name) and `Date = import date` (issue day equals `added` day, same rule as the list filter).
- Row actions: the redundant `Open` button is removed (title and row are links); every not-reviewed document gets the `Review` shortcut to the Suggestions tab.
- Tooltips explaining "Showing X of Y synced" (documents deleted in Paperless stay in Cortex but are not listed) and "Processed*" (= embeddings).
